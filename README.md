# File Embedding App with Rust

A desktop application built with Rust, EGUI, and Candle for generating text embeddings from files.

## Features
- [x] File selection dialog
- [x] Text file preview
- [ ] Embedding generation with Candle
- [ ] Embedding visualization
- [ ] Save/Load embeddings

## Getting Started

### Prerequisites
- Rust 1.70 or higher
- Cargo package manager

### Installation
```bash
git clone https://github.com/YOUR-USERNAME/embedding-app.git
cd embedding-app
cargo run
